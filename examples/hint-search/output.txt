  To export a document to PNG in Affinity Javascript, use the following pattern:
  
  1. Import the required modules: `Document`, `FileExportOptions`, and `FileExportArea` from `/document`
  2. Set your selection to specify what to export:
     - For the entire document: `doc.selection = Selection.create(doc, nodes)`
     - Or use `FileExportArea.createForWholeDocument()` to export all content
  3. Create PNG export options: `FileExportOptions.createWithPresetName('PNG')`
  4. Create an export area:
     - For selected nodes: `FileExportArea.createForSelection(doc.selection)`
     - For the whole document: `FileExportArea.createForWholeDocument()`
  5. Call the export method: `doc.export(targetPath, options, area)`
  
  The export will write the PNG file to the specified path, using the bounding box of the selected content as the canvas.
  
  **Important notes:**
  - If exporting specific content (not the whole document), you can set transparency by using `DocumentProperties` with `isTransparent=true`
  - On Windows, use backslash characters in file paths
  - There have been occasional timeout issues when writing to certain paths—if you encounter hangs, it may be a permissions issue
